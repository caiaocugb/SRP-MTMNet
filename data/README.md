# Example dataset

This directory contains four paired multimodal samples:

- Training: `11_1_0`, `16_20_0`
- Test: `1_7_0`, `2_5_0`

Each record in `SRP_MTMNet_TGRA.json` contains aligned optical and InSAR image
paths, image dimensions, panoptic segment metadata, instance boxes, and spatial
relationship triplets. `test_image_ids` contains only the two test samples. 
For annotation of spatial relationship triplets, see the paper.
